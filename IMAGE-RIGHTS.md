The file page treats the faithful reproduction as public domain in the United States and expressly notes that reuse may be restricted elsewhere. These notices do not guarantee every jurisdiction, clear all non-copyright rights, or imply museum endorsement. [Exact Seurat file licensing](https://commons.wikimedia.org/wiki/File:A_Sunday_on_La_Grande_Jatte,_Georges_Seurat,_1884.jpg#Licensing), [Public Domain Mark](https://creativecommons.org/publicdomain/mark/1.0/), [CC0 limitations](https://creativecommons.org/publicdomain/zero/1.0/).

## Verification and scope

All eight saved Met API records have `isPublicDomain: true`; their `primaryImage` URLs match the recorded sources above. The shipped eight Met files match the original download files in the build workspace by SHA-256. Current official API responses or object pages were checked for public-domain status. The Seurat source is recorded in the build's Commons source map; its dimensions match the rendition offered by the exact file page. A fresh remote byte comparison of that rendition was unavailable during this check because the direct request could not resolve the image host.

These notices document the bundled media. They do not assign a new blanket license to the whole package, select a license for the source code, or claim ownership of the paintings. Future API discoveries and users' own folder images are outside this nine-file record. Do not redistribute private images in a Workshop upload without the necessary rights.
